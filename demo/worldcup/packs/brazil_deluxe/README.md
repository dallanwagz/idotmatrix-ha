# Brazil World Cup — DELUXE pack (64x64 iDotMatrix)

10 looping, **full-colour cinematic** GIFs celebrating Brazil, the 5-time world champions. Unlike the
older flat-16-colour `brazil/` pack, this set leans into everything the 64x64 panel can actually do
(verified ~126 colours/frame, ~90 frames, gradients + dithering): per-pixel cloth folds, gradient
skies, gold speculars, bloom/glow, motion blur and smooth 15-20 fps motion.

Everything is generated by `gen_brazil_deluxe.py` (numpy for the pixel math, Pillow for compositing),
written through `assetlib.save_gif(..., dither=True)`. The generator **auto-tunes colours (144 -> 48)
and, only if needed, frame count** so every GIF stays under the ~95 KB BLE-safe ceiling while keeping
as much colour/motion as possible.

Rebuild everything (GIFs + a `*_preview.png` per GIF + `_montage.png` contact sheet):

```
python3 gen_brazil_deluxe.py
```

Files only — this generator never touches Bluetooth. Push via the normal carousel/push tooling.
